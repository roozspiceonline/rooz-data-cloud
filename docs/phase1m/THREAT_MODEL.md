# Phase 1M Threat Model

## Increment 5 threats

The browser gateway now contains a real outbound forwarding implementation.
The code remains unreachable from normal v2 Run dispatch in this increment,
but the security model must already assume hostile page content.

Threats include:

1. top-level SSRF
2. subresource SSRF
3. DNS rebinding
4. redirect-to-private-network attacks
5. credential/cookie leakage
6. POST/body exfiltration
7. unsupported browser resource channels
8. unbounded subresource fan-out
9. oversized responses/screenshots
10. bypassing interception to direct Internet
11. response-header persistence through Set-Cookie
12. tampering with gateway or Run policy digests
13. cross-Run Unix-socket reuse
14. unvalidated browser output artifacts

## Mitigations implemented before activation

- browser remains `--network none`
- only Unix-domain-socket gateway transport
- exact immutable gateway-policy digest on every request
- strict request fields; no headers or request body
- GET/HEAD only
- exact allowlisted HTTPS hostname
- IP literals denied
- global DNS only
- validated address pinning
- TLS hostname/SNI verification retained
- every subresource independently validated
- every redirect Location independently validated
- redirect target is validated again when Chromium follows it
- Set-Cookie not returned
- content-length regenerated by Playwright rather than trusted
- request/redirect/byte/time budgets
- unsupported resource types aborted
- service workers blocked
- direct WebSocket/WebRTC networking has no browser network interface
- viewport-only bounded screenshots
- navigation result binds request, browser-policy and egress-policy digests

## Activation risk still outstanding

The live forwarding code is intentionally **not wired into normal v2 worker
execution** yet.

The final increment must independently validate result artifacts and
provenance, preserve exact canary lineage, and make any activation transition
narrow and reversible. Until then:

```text
v2 START dispatch              blocked
v2 control-plane activation    denied
browser live forwarding        unavailable to normal Runs
```
